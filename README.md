**# Customer Shopping Behavior Analysis**



**## Project Overview**



This project analyzes customer shopping behavior to understand purchasing patterns, customer preferences, discounts, and product performance.



**## Tools \& Technologies**

**-** Python

\- Pandas

\- MySQL

\- SQL

\- Power BI

\- Jupyter Notebook



**## Project Workflow**

1\. Explored the dataset using Python and Pandas.

2\. Performed data analysis.

3\. Imported customer data into MySQL.

4\. Wrote SQL queries to answer business questions.

5\. Created an interactive Power BI dashboard.



**## Key Analysis Areas**

\- Revenue by Gender

\- Customer Purchasing Patterns

\- Product Ratings

\- Discount Usage

\- Customer Segmentation

\- Product and Category Performance



**## Project Files**

\- Jupyter Notebook

\- CSV Dataset

\- SQL Queries

\- Power BI Dashboard
